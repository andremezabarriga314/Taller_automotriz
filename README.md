## ACERCA DEL PROYECTO

MotorTech Service es una aplicacion web desarrollada con Python y Django para administrar las operaciones de un taller automotriz. Centraliza la informacion de clientes, vehiculos, citas, diagnosticos, ordenes de servicio y repuestos.

## FUNCIONALIDADES

- Gestion de clientes.
- Administracion de vehiculos.
- Agenda y citas.
- Registro de diagnosticos.
- Gestion de ordenes de servicio.
- Control de repuestos e inventario.
- Detalles de ordenes.
- Dashboard con indicadores y actividad reciente.
- Reportes.
- Autenticacion de usuarios.

## INSTALACION

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
cd MotorTech_Service
```

### 2. Crear entorno virtual

```bash
python -m venv .venv
```

### 3. Activar entorno virtual en Windows

```powershell
.\\.venv\\Scripts\\Activate.ps1
```

### 4. Instalar dependencias

```bash
pip install -r requirements.txt
```

### 5. Preparar base de datos

```bash
python manage.py migrate
```

### 6. Crear administrador

```bash
python manage.py createsuperuser
```

### 7. Ejecutar el proyecto

```bash
python manage.py runserver
```

Acceso: http://127.0.0.1:8000/
